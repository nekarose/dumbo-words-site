덤보의 단어 바다개인정보 문서 초안

개인정보처리방침 작성 초안

정식 개인정보처리방침이 아니에요. 운영 주체·문의처·광고와 Firebase의 최종 운영 방식이 확정되기 전에는 스토어 제출용으로 사용하지 않아요.

초안 작성일: 2026년 10월 4일 · 시행일: 미확정

1. 운영 주체와 문의처

운영 주체의 명칭, 개인정보 담당 연락처, 지원 이메일을 확정한 뒤 기재해요. GitHub 계정이나 로그인 이메일을 공식 문의처로 임의 지정하지 않아요.

2. 현재 기기에 저장하는 기록

  • 스테이지 진행과 별, 단어별 정답·오답 기록
  • 조개 잔액과 홈 배경 소유·선택 기록
  • 소리·발음 속도 설정과 완료한 판 수 등 앱 운영 기록

현재 앱은 별도 계정 로그인 없이 기기 안에 학습 기록을 저장해요. 운영체제의 백업·복원 동작은 기기 설정에 따라 달라질 수 있어요.

3. 제3자 서비스 검토

현재 코드에는 Google Mobile Ads와 동의 관리 기능, 기기의 영어 음성 합성 기능이 포함되어 있어요. 광고 SDK가 있는 상태에서 모든 데이터가 기기 안에만 머문다고 선언하지 않아요.

정식 문서에는 실제 광고 설정·대상 연령에 따른 수집 항목, 목적, 제공자, 보유 기간, 적용되는 국외 처리와 이용자의 권리를 확인해 기재해야 해요.

Firebase는 현재 미적용이에요. 추후 적용 제품과 수집 방식이 정해지면 이 문서와 스토어 개인정보 신고도 함께 수정해요.

영어 발음은 기기 TTS 엔진을 사용해요. 엔진 공급자와 음성의 오프라인·네트워크 사용 여부도 출시 검증에 포함해요.

4. 삭제와 설정 변경

현재 앱의 ‘기록 지우기’는 학습 기록과 조개를 초기화하지만 구매한 홈 배경 소유권과 일부 설정·운영 기록은 남겨요. 이 동작을 모든 정보 삭제와 같다고 표현하지 않아요.

최종 보유·삭제 기준, 문의를 통한 처리 절차, 필요 시 광고 동의 변경 방법을 확정해 기재해요.

5. 어린이 개인정보 보호

어린이 대상 출시 여부와 광고·진단 서비스 사용 범위를 먼저 확정해요. 해당 스토어 정책과 적용되는 개인정보 규정을 검토하고, 필요한 보호자 접근 및 안내 절차를 마련해요.

6. 정식 공개 전 확인

  • 운영자 명칭과 문의처
  • 대상 연령, 사용 SDK와 실제 수집·전송 범위
  • 보유·삭제·동의 변경 절차와 시행일
  • App Store·Google Play의 데이터 신고와 일치 여부
